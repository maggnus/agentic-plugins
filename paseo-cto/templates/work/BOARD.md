# Board

time of the last change. Only the CTO changes a row; `land.py` marks it done, stamps the time and
removes the task file.

Marks: `[x]` done · `[~]` in work · `[!]` blocked · `[=]` paused · `[ ]` ready to start

[FINDINGS.md](FINDINGS.md).
