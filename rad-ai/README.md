# `rad-ai`

Планируемый плагин для Codex и Claude Code: адаптация **Rapid Application Development (RAD)**
к разработке приложений агентами искусственного интеллекта. Цель — сокращать время от
потребности до принятого работающего изменения, сохраняя качество кода, архитектурные
границы и возможность дальнейшего развития системы.

Метод должен работать и в небольшом приложении, и в большой существующей кодовой базе.
Число агентов, объём изучаемого кода и состав проверок будут определяться зависимостями
изменения, риском и результатами измерений.

Текущий результат — [план до первого выпуска навыков](PLAN.md). Полное исследование,
методология, эксперименты и навыки ещё не выполнены. Плагин пока не включён в каталог
и недоступен для установки.

План предусматривает изучение первоисточников RAD и смежных методов, исследование
особенностей разработки ИИ-агентами, проектирование цикла, мысленные эксперименты,
проверку на реальных проектах и упаковку общего набора навыков для обеих платформ.
Каждый этап заканчивается результатом, который можно проверить, прежде чем продолжать.

После реализации публикация и установка будут выполняться по
[правилам общего выпуска](../README.md#release): только из `maggnus/agentic-plugins`
на GitHub, с привязкой к опубликованному неизменяемому тегу. Локальная установка запрещена.
