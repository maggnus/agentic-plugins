# Правила репозитория

- Плагины предназначены только для Codex и Claude Code; обе платформы обязательны.
- Локальная установка строго запрещена. Устанавливать и обновлять плагины можно
  только из `maggnus/agentic-plugins` на GitHub с привязкой к опубликованному
  неизменяемому тегу выпуска.
- Нельзя устанавливать из локального каталога или клона, подключать локальный
  каталог плагинов, копировать файлы в каталоги установки или вручную менять кэш.
- Каждое изменение требует повышения единой версии всех плагинов и публикации в GitHub.
  Все манифесты Claude Code используют версию тега без `v`; все манифесты Codex —
  ту же версию с общим техническим суффиксом `+codex.<timestamp>`.
- Порядок публикации и команды установки находятся в `README.md`.
